# 🕌 Asrama Al-Istiqomah

### Pesantren Nurul Huda Munjul — Cirebon, Jawa Barat

---

## 📖 Tentang Proyek

Website resmi **Asrama Al-Istiqomah**, salah satu asrama santri putra di bawah naungan

**Pondok Pesantren Nurul Huda Munjul** yang dikelola oleh **Yayasan Nurul Huda Munjul**.

Website ini dibangun sebagai media informasi dan pengenalan asrama kepada masyarakat luas,

calon santri, serta wali santri yang ingin mengetahui lebih lanjut tentang kehidupan dan

kegiatan di Asrama Al-Istiqomah.

---

## ✨ Fitur Website

- 🏠 **Halaman Utama** — Sambutan dan kutipan inspiratif

- 📋 **Tentang Asrama** — Sejarah dan profil singkat asrama

- 👳 **Masyaikh** — Profil para pengasuh asrama

- 🏫 **Fasilitas** — Informasi sarana dan prasarana

- 🕐 **Jadwal Kegiatan** — Aktivitas harian santri

- ❓ **FAQ** — Tanya jawab umum seputar pendaftaran

- 📍 **Lokasi** — Peta dan alamat asrama

- 📨 **Formulir Pendaftaran** — Pendaftaran langsung via WhatsApp

- ⭐ **Feedback** — Kolom masukan dari pengunjung
